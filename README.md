# Titanic Survival Prediction

## Project Overview

This project predicts whether a Titanic passenger survived
using Machine Learning and Deep Learning models.

## Models Used

### Machine Learning
- Logistic Regression
- Decision Tree
- Random Forest
- Gradient Boosting
- XGBoost

### Deep Learning
- Artificial Neural Network (ANN)
- 1D Convolutional Neural Network (1D CNN)

## Features

- Passenger Class
- Sex
- Age
- Siblings/Spouses
- Parents/Children
- Fare
- Embarkation Port

## Evaluation Metrics

- Accuracy
- Precision
- Recall
- F1 Score
- ROC-AUC

## Streamlit Application

The trained model is deployed using Streamlit.
